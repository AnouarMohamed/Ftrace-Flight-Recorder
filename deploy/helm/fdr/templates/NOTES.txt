FDR (Flight Data Recorder) has been installed as a DaemonSet.

1. Watch pods come up on each node:

  kubectl -n {{ .Release.Namespace }} get pods -l app.kubernetes.io/instance={{ .Release.Name }} -o wide

2. Inspect logs:

  kubectl -n {{ .Release.Namespace }} logs -l app.kubernetes.io/instance={{ .Release.Name }}

3. Host trace files are written under:

  {{ .Values.logs.hostPath }}

4. Edit probe configuration in values.yaml (config section), then upgrade:

  helm upgrade {{ .Release.Name }} ./deploy/helm/fdr -f my-values.yaml

{{- if .Values.monitoring.podMonitor.enabled }}
5. A PodMonitor named {{ include "fdr.fullname" . }} was created in namespace
   {{ default .Release.Namespace .Values.monitoring.podMonitor.namespace }}.
{{- else }}
5. Prometheus discovery is disabled. Set monitoring.podMonitor.enabled=true
   when the Prometheus Operator CRDs are installed.
{{- end }}

NOTE: Pods run privileged with host tracefs mounted. Restrict who can change the
DaemonSet, image, values, and ConfigMap. Module access is {{ ternary "enabled" "disabled" .Values.modules.enabled }}.
